This is a repo for an object detection project that detects different types of rats' bones collected from owl pellets.
First, download the best.pt file in the best model folder. The size is about 50 MB.
Second, run the Final_completed_ratbone_owl.IPYNB. Click the colab link to run the notebook in VM. For the connection type, choose T4 GPU or L4 GPU (depending on whether it is a free or paid Colab account)
Follow the instructions in the notebook. Sometimes, uploading the model would fail partially (but not indicated); it would only show a weird "qkv" error when running the code.
If this happens, reupload the data upload code again.
